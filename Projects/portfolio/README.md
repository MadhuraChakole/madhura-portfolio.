# Portfolio

A minimal, professional single-page portfolio — ready for LinkedIn and project listings.

## Customize

Edit `index.html` and replace placeholders:

- **Your Name** — hero, header, footer
- **About** — bio, location, education, focus
- **Skills** — your tech stack
- **Projects** — titles, descriptions, Live/Code links, tags
- **Contact** — email, LinkedIn, GitHub URLs

## Preview locally

Open `index.html` in your browser, or run a local server:

```bash
npx serve .
```

## Deploy (free)

### GitHub Pages

1. Push this folder to a GitHub repo
2. Settings → Pages → Source: **main** branch, folder **/ (root)**
3. Your site will be at `https://your-username.github.io/repo-name`

### Netlify / Vercel

Drag the folder or connect the repo — no build step needed.

## LinkedIn

Add the live URL to:

- **Featured** section on your profile
- **Contact info** → Website
- Project descriptions when listing portfolio work
